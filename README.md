# 🌱 CarbonGPT

CarbonGPT is an AI optimization platform that reduces the **carbon footprint of AI usage** by analyzing prompts, optimizing them, and intelligently routing them to energy-efficient models.

---

## 🚀 Problem

Modern AI models consume significant computational power, leading to high energy usage and carbon emissions.

Most users:

* Write unnecessarily long prompts
* Use large models even for simple tasks
* Generate long outputs without realizing energy cost

---

## 💡 Solution

CarbonGPT addresses this by:

* 🔍 **Prompt Analysis** – Estimates token usage and energy impact
* ✂️ **Prompt Optimization** – Suggests shorter, efficient prompts
* 🤖 **Model Routing** – Sends simple prompts to smaller models
* 🌍 **Region-Based Energy Calculation** – Estimates carbon impact based on location
* 📉 **Output Awareness (Future Scope)** – Optimize generated responses to reduce energy waste

---

## ⚙️ How It Works

1. User enters a prompt
2. System calculates token usage
3. Estimates energy consumption
4. Suggests optimized prompt
5. Routes to appropriate model (SLM / LLM)
6. Returns response with reduced compute usage

## 🔧 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/carbongpt.git
cd carbongpt
```

### 2. Setup Backend

```bash
cd carbongpt-backend
npm install
npm start
```

### 3. Setup Frontend

```bash
cd carbongpt-frontend
npm install
npm run dev
```
